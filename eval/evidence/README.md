# Evidence

What B5a's method was checked by, kept with it:
- `mutations.md`: the mutation pass (`eval/mutate.py`), each rule of the method broken once, every mutation caught by a named test, after a clean baseline;
- `dry-run.md`: the dry run's report, the harness end to end on the scripted model (never data), with what reached the agent.

The depth pilot's results (`--pilot`) go here too when it runs, before the set is frozen, with any task it led to replace.

Each names the commit it ran at. Re-run them with the commands in `eval/README.md`.
